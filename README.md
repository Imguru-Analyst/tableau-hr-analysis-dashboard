# 📊 HR Analysis Dashboard – Tableau

## 📌 Project Overview

An interactive **HR Analytics Dashboard built using Tableau** to analyze employee workforce, attrition, demographics, departments, job roles, education, and age groups.

## 🏢 Project Domain

**Human Resources (HR) Analytics**

## 🎯 Objectives

- Analyze total and active employees
- Monitor employee attrition and attrition rate
- Analyze attrition by department and gender
- Analyze employee distribution by age group
- Analyze employee count by job role
- Analyze attrition by education field

## 🛠️ Tools Used

- Tableau
- Excel / CSV
- Data Analysis
- Data Visualization

## 📊 Key KPIs

- **Total Employees:** 1,470
- **Active Employees:** 1,233
- **Attrition:** 237
- **Average Age:** 37
- **Attrition Rate:** 16.12%

## 📈 Dashboard Analysis

- **Department-wise Attrition**
- **Employee Count by Age Group**
- **Employee Count by Job Role**
- **Gender-wise Attrition**
- **Education Field-wise Attrition**
- **Gender & Age Group Attrition Analysis**

## 💡 Key Insights

The dashboard helps understand **workforce distribution and employee attrition patterns**, enabling HR teams to identify areas requiring further analysis and support data-driven decisions.
